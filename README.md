`Tab Save`는 현재 창의 탭을 폴더처럼 저장하는 Chrome 및 Brave 확장 프로그램입니다. 잠시 탭을 정리했다가 이어서 작업하거나, 자주 사용하는 페이지 묶음을 한 번에 열 때 사용할 수 있습니다.

## 주요 기능

- 현재 창의 탭을 하나의 세션으로 저장
- 필요한 탭만 골라 담는 즐겨찾기 폴더
- 저장한 폴더의 이름 변경, 탭 확인 및 삭제
- 새 탭 또는 현재 탭에서 복원
- 저장 후 기존 탭 유지 또는 정리
- 한국어와 영어, 시스템·라이트·다크 테마
- 저장 데이터 백업 및 다른 브라우저로 이동

## 설치

### 배포 파일로 설치

1. 저장소의 `Releases`에서 최신 ZIP 파일을 내려받습니다.
2. ZIP의 압축을 풉니다.
3. Chrome에서는 `chrome://extensions`, Brave에서는 `brave://extensions`를 엽니다.
4. 우측 상단의 `개발자 모드`를 켭니다.
5. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
6. 압축을 푼 폴더 중 `manifest.json`이 들어 있는 폴더를 선택합니다.

### 소스 코드로 설치

```bash
npm install
npm run build
```

빌드가 끝나면 브라우저의 확장 프로그램 관리 화면에서 `dist/` 폴더를 불러옵니다.

## 사용 방법

### 현재 창 저장하기

1. 브라우저 도구 모음에서 Tab Save를 엽니다.
2. 세션 이름을 입력합니다.
3. `저장`을 누릅니다.

`chrome://`처럼 브라우저 내부에서만 사용하는 페이지는 저장되지 않습니다.

### 저장한 탭 다시 열기

- 팝업의 최근 저장 목록에서 `열기`를 누릅니다.
- 모든 목록을 정리하거나 복원 방식을 바꾸려면 `관리`를 누릅니다.

### 즐겨찾기 폴더 사용하기

1. 관리 페이지에서 즐겨찾기 폴더를 만듭니다.
2. `탭 추가`를 누릅니다.
3. 현재 창에서 보관할 탭만 선택합니다.

## Chrome에서 Brave로 옮기기

1. Chrome의 Tab Save 관리 페이지에서 설정을 엽니다.
2. `백업 파일 내보내기`를 눌러 JSON 파일을 저장합니다.
3. Brave에 Tab Save를 설치하고 관리 페이지의 설정을 엽니다.
4. `백업 파일 불러오기`에서 저장한 JSON 파일을 선택합니다.
5. 표시된 폴더와 탭 개수를 확인한 뒤 `교체하고 불러오기`를 누릅니다.

백업 파일에는 저장한 탭의 제목과 URL, 폴더 정보, 앱 설정이 포함됩니다. 불러오면 대상 브라우저의 기존 Tab Save 데이터는 백업 내용으로 교체됩니다.

## 설정

관리 페이지의 우측 상단 설정 버튼에서 다음 항목을 바꿀 수 있습니다.

- 기본 복원 방식
- 세션 저장 후 탭 처리 방식
- 즐겨찾기 추가 후 탭 처리 방식
- 테마와 언어
- 백업 파일 내보내기 및 불러오기

## 데이터와 권한

저장한 폴더와 설정은 현재 브라우저 안에만 보관되며 자동으로 다른 기기나 브라우저에 전송되지 않습니다.

- `tabs`: 현재 창의 탭을 저장하고 다시 열 때 사용합니다.
- `storage`: 저장한 폴더와 설정을 보관할 때 사용합니다.
