# Lessons

- 삭제 실행취소 UI를 복제할 때는 메시지만 옮기지 말고 남은 초 상태, interval 정리, unmount cleanup까지 같이 점검한다.
- 전역 설정을 추가할 때는 저장만 구현하지 말고 실제 진입점 동작과 기본 UI 값이 모두 같은 설정을 읽는지 같이 확인한다.
- 테마 설정에 시스템 옵션이 있으면 초기 적용만 하지 말고 `matchMedia` 변경 이벤트까지 연결해 실시간으로 따라가게 한다.
- 시각적 타이머는 텍스트 카운트보다 애니메이션 진행 인디케이터가 더 자연스러우므로 상태도 프레임/진행률 기준으로 단순화할 수 있는지 먼저 본다.
- 설정 설명 문구는 내부 구현 의도가 아니라 사용자가 지금 무엇을 바꾸는지 바로 이해할 수 있는 표현으로 쓴다.
- 아이콘 리디자인은 형태만 보지 말고 색 온도까지 확인해서 제품 톤과 사용자 선호를 같이 맞춘다.
